# PlainAgri site

Public marketing site for the PlainAgri mobile apps (iOS + Android). Static HTML/CSS/JS, no build step to serve.
Canonical: https://equalinformation.com/plain-agri-site/

- Pages are generated by `python3 tools/gen.py` (shared nav/footer); edit that file, regenerate, commit the output.
- Preview: `python3 -m http.server` in this folder.
- Rules: marketing venue that entices without giving away the full library; authentic claims only; no trackers; brand voice per the owner's brand-voice rule (one experienced engineer amplified by AI agents).
- **Keep in sync with the apps**: see `CHANGELOG-SYNC.md`.
